**Kamoder** replaces the vendor app on Anyka AK3918 cameras with a small, auditable
stack written in Rust. It runs from the SD card, talks to no cloud, and exposes
standard protocols — SSH, a web admin UI, ONVIF, RTSP and Prometheus metrics — so
the camera works with your own NVR or Home Assistant instead of a phone app.

It grew out of the shell/C [SD-card hack](https://gitea.raspiweb.com/Gerge/Anyka_ak3918_hacking_journey)
for the AK3918**EV200**, and now targets the newer AK3918**AV100** as well.

<Callout type="warn" title="Work in progress">
  On the AV100 the network, admin and lighting stack is verified on hardware, and
  live snapshots and hardware H.264 from both sensors work without any vendor
  library. RTSP and ONVIF streaming of that video still await a full on-camera check.
  See [Cameras](/docs/cameras) for the exact status of each feature.
</Callout>

## Why

<Cards>
  <Card icon={<Lock />} title="Private by default">
    The vendor app phones home and pairs through a cloud account. Kamoder never
    starts it, and nothing leaves your network unless you configure it.
  </Card>
  <Card icon={<Network />} title="Standard protocols">
    ONVIF Profile S (device, media, PTZ, imaging), RTSP with Digest auth, SSH on
    port 2222 and a JSON API behind the web UI.
  </Card>
  <Card icon={<Wifi />} title="Stays online">
    A Wi-Fi reconciler with rollback to the last good network and a recovery ladder
    that reloads the driver or power-cycles the USB radio when it wedges.
  </Card>
  <Card icon={<Cpu />} title="Fits 32 MB of RAM">
    One supervisor, a handful of small services and no interpreter. Every binary is
    cross-compiled for the ARM926EJ-S and uClibc.
  </Card>
  <Card icon={<ShieldCheck />} title="Signed releases">
    Every release is built in GitHub Actions and signed with Sigstore, with a
    build-provenance attestation you can verify offline.
  </Card>
  <Card icon={<Cctv />} title="Reversible">
    Everything lives on the SD card. The optional autostart patch changes one file
    in flash and ships with a verified rollback.
  </Card>
</Cards>
