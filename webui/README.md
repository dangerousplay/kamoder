# anyka webui

Admin SPA for the camera, served from the SD card by `web`
(see `.specs/features/web-admin-onvif/design.md`).

Stack: Vite 8, React 19, TypeScript, Tailwind CSS v4, shadcn/ui (radix-nova,
neutral), react-router.

## Develop

```sh
npm install
ANYKA_URL=http://<camera> npm run dev
```

`/api` is proxied to `ANYKA_URL` (default `http://127.0.0.1:8080`, i.e. the
itest guest's port 80 forwarded to the host). SSE log streams pass through.

## Build

```sh
npm run lint
npm run build:camera   # dist/ + precompressed .gz/.br next to each asset
```

For the SD card use `./x webui` (xtask, added later), which builds and stages
`dist/`. No source maps are emitted.

## Layout

- `src/lib/api.ts` — typed API client and types (token in `sessionStorage`
  `anyka.token`; 401 clears it and returns to `/login`).
- `src/lib/auth.tsx` — `AuthProvider`, `useAuth`, `RequireAuth`, `RequireAdmin`.
- `src/components/layout/` — sidebar shell, header, theme toggle, user menu.
- `src/pages/` — one file per route (lazy-loaded chunks).
- `src/components/<feature>/` — page parts: `logs/` (tail + SSE hook, 2000-line
  cap), `ptz/` (hold-to-move pad, presets), `settings/`, `users/`, `video/`
  (snapshot poller), `services/`, `common/` (confirm dialog).
- `src/hooks/use-polling.ts` — `usePolling(fn, ms)`; pauses in hidden tabs.
- `src/components/ui/` — generated by `npx shadcn@latest add <name>`.
